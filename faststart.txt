PREREQUISITES
  • Docker (for ESP32 builds)
  • git, make, gcc, zlib-dev  (for Linux index builder)
  • Python 3.9+ with gzip, struct, ctypes (stdlib only)
  • GoogleNews-vectors-negative300.bin.gz  (download separately, ~1.5 GB)
  • nn20db SDK release-1.1.0 tarballs (see step 1)

--------------------------------------------------------------------------------
STEP 1 — Install the nn20db SDK
--------------------------------------------------------------------------------

  Download the install script and both tarballs from the GitHub release page:
    https://github.com/brunokeymolen/nn20db-sdk/releases/tag/release-1.1.0

  No git clone needed — fetch the script directly:

    curl -fLO https://raw.githubusercontent.com/brunokeymolen/nn20db-sdk/release-1.1.0/scripts/install-sdk.sh
    chmod +x install-sdk.sh

    (!) CHANGE LINE 32: repo_root="$(cd "${script_dir}" && pwd)"

    # Linux SDK (needed for build_index and the Python CLI)
    ./install-sdk.sh linux https://github.com/brunokeymolen/nn20db-sdk/releases/download/release-1.1.0/nn20db-sdk-linux-1.1.0.tar.gz

    # ESP32-S3 SDK (needed for the ESP32 firmware)
    ./install-sdk.sh esp32 https://github.com/brunokeymolen/nn20db-sdk/releases/download/release-1.1.0/nn20db-sdk-esp32s3-1.1.0.tar.gz

    rm install-sdk.sh

  After install the layout under sdk/ is:
    sdk/linux/current/   — Linux shared library + pkg-config
    sdk/esp32/current/   — ESP32 IDF component (nn20db/)

  The sdk/ directory is gitignored; repeat this step on each fresh clone.

--------------------------------------------------------------------------------
STEP 2 — Build the Linux index builder
--------------------------------------------------------------------------------

  Requires: nn20db Linux SDK (step 1), zlib-dev, libm, gcc/make

    cd linux/build_index
    make

  Binary produced: ./build_word2vec_index

--------------------------------------------------------------------------------
STEP 3 — Build the HNSW index from GoogleNews vectors
--------------------------------------------------------------------------------

  Recommended first run: limit to 200 000 words (fast, ~2 GB RAM peak).
  Full 3M-word run: ~6–8 hours, ~18 GB RAM.

    ./build_word2vec_index \
        /path/to/GoogleNews-vectors-negative300.bin.gz \
        /path/to/output_db \
        --limit 200000

  Options:
    --limit N      only index the first N words (default: all)
    --ef-search N  ef_search used for the self-test (default: 100)
    --test N       run self-test with N query vectors after build (default: 10000)

  The program will print recall@10 at the end. Aim for recall > 0.90.

  The database directory can be on any local filesystem (ext4, etc.).
  For SD card use 8.3 filenames: copy it as /sdcard/nand0/word2vec/

STEP 4 — Test with the Linux CLI
--------------------------------------------------------------------------------

  

  Requires: nn20db Linux SDK installed (step 1), Python 3
            python bindings : make -C api/python/ 


    cd linux/cli

    # Interactive REPL (local Linux search)
    python word2vec_cli.py \
        --db /path/to/output_db \
        --word-vectors /path/to/GoogleNews-vectors-negative300.bin.gz \
        --limit 200000
        --local-search 


  At the prompt:
    > king                     # search for a word
    > king - man + woman       # vector arithmetic (classic analogy)
    > queen                    # any expression

--------------------------------------------------------------------------------
STEP 5 — Copy database to SD card
--------------------------------------------------------------------------------

  Format SD card as FAT32.  Copy the database directory, preserving 8.3 names:

    cp -r /path/to/output_db/* /media/<sdcard>/nand0/word2vec/

  Required SD card layout:
    <SD root>/nand0/word2vec/   ← nn20db database files

  Insert SD card into the ESP32-S3 board before flashing or reset after.

--------------------------------------------------------------------------------
STEP 6 — Build and flash the ESP32-S3 firmware (using Docker)
--------------------------------------------------------------------------------

  The easiest way is to use 'Visual Studio Code' and the Extention 'Dev Containers' from Microsoft.

  Pres 'F1' -> Dev Containers : Reopen In Container

  (plug in the ESP before switching to the container, this to keep the serial interface available)

  - once done you have a full ESP IDF environment to build and flash.
    (set the wifi credentials, see STEP 7)

    
    cd esp32/word2vec_search
    
    #Initiate the ESP IDF environment
    get_idf

    # Clean
    make clean

    # Set ESP32-S3 target 
    make set-target-s3
    
    # Compile
    make build

    # Flash to board (default port: /dev/ttyACM0)
    make flash

    # Monitor
    make monitor

    # Override serial port
    make flash-monitor PORT=/dev/ttyUSB0

  

--------------------------------------------------------------------------------
STEP 7 — Configure Wi-Fi credentials
--------------------------------------------------------------------------------

  Before the first flash, set your Wi-Fi SSID and password:

  cd esp32/word2vec_search


  edit/create : sdkconfig.defaults.local

  # Local Wi-Fi credentials — NOT committed to git (see .gitignore)
  CONFIG_WORD2VEC_WIFI_SSID="<your access point ssid>"
  CONFIG_WORD2VEC_WIFI_PASSWORD="<your password>"

--------------------------------------------------------------------------------
STEP 8 — Search from Linux CLI via ESP32 (phase 1 demo)
--------------------------------------------------------------------------------

  Once the ESP32 is running and connected to Wi-Fi, the board will print its
  IP address on the serial monitor.

    python linux/cli/word2vec_cli.py \
        --word-vectors /path/to/GoogleNews-vectors-negative300.bin.gz \
        --limit 200000 \
        --esp32 <ESP32_IP>

  At the prompt, expressions are evaluated on Linux; the resulting 300-D vector
  is sent over TCP to the ESP32 (port 9900) which performs the HNSW search and
  returns top-k results.

  Example
  -------
  bruno@bruno-desktop ~/projects/nn20db-word2vec/linux/cli ⎇ main $ python3 word2vec_cli.py --db /tmp/vectordb/w2v3m --word-vectors /home/bruno/datasets/GoogleNews-vectors-negative300.bin --esp32 192.168.0.201:9900


--------------------------------------------------------------------------------
WIRE PROTOCOL (port 9900)
--------------------------------------------------------------------------------

  Request  : uint16 k + uint16 ef_search + 300 × float32 little-endian
           =  1204 bytes
  Response : k × (32-byte word + 4-byte float32 distance LE)  =  k × 36 bytes
  k default: 10

  REPL syntax: append '; N' to override ef_search for one query, for example:
    king + woman ; 25

--------------------------------------------------------------------------------
HNSW PARAMETERS
--------------------------------------------------------------------------------

  Parameter          Linux build  Linux CLI  ESP32 search
  ─────────────────  ───────────  ─────────  ────────────
  M                  32           —          —
  ef_construction    400          —          —
  ef_search          —            100        32
  Metric             L2 (norm'd)  L2         L2

  Tune ef_search lower on ESP32 if search is too slow; raise it for more recall.
